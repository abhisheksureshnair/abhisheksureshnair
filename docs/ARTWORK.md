## Saved assets

- `assets/background/violet-citadel.webp`: original 3:1 cityscape, optimized to 1536×512. Shared by the hero, decorative Contribution City and footer.
- `assets/characters/developer-monarch.webp`: original developer character with transparent alpha, optimized to 480×720. Used in About, Project Focus, the technology galaxy and Hunter ID.
- `assets/hero/`, `assets/cards/`, `assets/projects/`, `assets/stats/`, `assets/footer/`: editable SVG compositions generated by the Python scripts. Project illustrations are original abstract vectors and explicitly labelled as illustrations, not screenshots.

No name, title, numbers or product UI were generated into the raster illustrations. Typography and data are composed separately as inspectable SVG text. Each ambient animation uses a six-second opacity/position cycle; text remains static. Static companions remove all animation elements. The original GIF timing remains unchanged.

The source PNGs are retained in the local image-generation output directory; the repository contains optimized derivatives rather than large intermediates. To rebuild compositions, run `python3 scripts/build_profile.py`. The built-in tool was used, not the API/CLI fallback.
